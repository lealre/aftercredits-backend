## Current state (grounded by scan, 2026-07-25)
Frontend uses raw `fetch` wrappers (`src/services/backendService.ts` `authFetch`, `src/services/authService.ts`) inside manual `useEffect` hooks. **No StrictMode** (`src/main.tsx`), so all duplicates are real, not dev artifacts. **`@tanstack/react-query` is installed and a `QueryClient` is created in `src/App.tsx` but never used for any fetch** — dead dependency. No shared user state / context.

Key facts:
- Auth token: `localStorage["access_token"]` (write `authService.saveLoginData`, read `getToken`, clear `clearToken`). `authFetch` sets `Authorization: Bearer` per request; on 401 → clear token + `window.location.replace('/login')`.
- Current user is fetched by id via `GET /api/users/{id}` (`fetchUserById`) in ≥4 places: `Header.tsx:47`, `UserAccount.tsx:38`, `Groups.tsx:51`, `Index.tsx:102` — none shared. Backend already exposes `GET /users/me` (`GetUserMe`) but the FE doesn't use it.
- `Header` is rendered by each page and remounts per navigation → refetches user each nav; plus each page load fires two identical user fetches (page + Header).
- Backend embeds `episodes` in the title document; the group-titles list response `GroupTitleDetail` (`internal/services/groups/types.go:59-67`) embeds `titles.Title`, so **every title in a group list carries its full `episodes` array**. Episodes are consumed in the FE only in `MovieModal.tsx` (per-season image, first-episode date, count). `seasons` summary (`Season{season, episodeCount}`) is small and used by cards/selectors.

## Backend design (tagged `v0.0.13`)
1. **New endpoint** `GET /titles/{id}/episodes` — **any authenticated user** (NOT admin-gated). Rationale: regular group members open the movie modal, so this must not require `RoleAdmin` like the admin-only `GET /titles` list does. Episodes are title-global (not group-scoped), so a plain authenticated check is sufficient — no group-membership check needed. Confirm the exact middleware wiring against the existing authed-but-not-admin routes during implementation.
   - Returns the title's episodes. Shape: reuse the existing episode JSON already used inside `titles.Title` (same fields the FE `Episode` type expects) so the FE mapper is unchanged. Return `{ "episodes": [...] }` (or bare array — decide in plan; prefer an object for forward-compat).
   - Routed through the **service layer** (`titles` service method, e.g. `GetEpisodes(db, ctx, titleId)`), per CONVENTIONS.md §1. Handler translates `mongodb.ErrRecordNotFound` → 404 and uses `titles.ErrorMap`.
2. **Trim `episodes` from the group-titles list response.** In the `GroupTitleDetail` mapping (`internal/services/groups/mapper.go` / wherever `titles.Title` is embedded for the list), set `Episodes` to nil/empty so the list stays light. Keep `Seasons` summary. Approach options to settle in the plan:
   - (a) zero `Episodes` in the group-title mapping only (single-title `GET /titles/{id}` may still include them — acceptable), or
   - (b) give the list its own title view without episodes.
   Prefer (a): least churn, and only the list is the bloat source.
3. **Tests** (Go, testcontainers): new endpoint returns episodes for a series and 404 for unknown id; group-titles list response no longer includes `episodes` but still includes `seasons`/`seasonsWatched`.
4. **Delivery:** branch `v0.0.13`, PR `v0.0.13 — …`, tag on merge, Docker Hub `v0.0.13` + `latest`, Pi deploy on user's word (see [[pi-deploy-runbook]]). No new env vars.

## Frontend design (committed, not tagged)
1. **`UserProvider` (React Context)** at app root.
   - On mount, if a token exists, fetch `GET /users/me` **once**; hold `{ user, loading, error }` in memory. Expose `refresh()` and `logout()` (clears token + user, redirects to `/login`).
   - `Header` and all pages consume `useUser()` instead of calling `fetchUserById` — removes per-page duplicate and per-navigation refetch.
   - Add `fetchMe()` in `backendService` hitting `/users/me`.
2. **Watchlist double movie-call fix.** Seed `orderBy`/`ascending` **synchronously** from `localStorage` in `useState` initializers (mirroring how `watchedFilter`/`titleType` are already seeded in `Index.tsx:22-33`), so no post-mount param change re-fires the `useMovies` effect. Result: one `GET /groups/{id}/titles` on load.
3. **Episode lazy-load.** `MovieModal` fetches `GET /titles/{id}/episodes` when it opens (guarded so it fetches once per open; show a small loading state in the season/episode area). Replace reads of `movie.episodes` with modal-local episode state. List/card code stops relying on `episodes` (uses `seasons` summary only).
4. **Error handling.**
   - User/data fetch failure → visible error (toast + inline state) with a retry; do **not** silently render the `'User'` default as the only signal.
   - Remove the aggressive auto-logout in `UserAccount.tsx:40-48` for generic failures; only 401 (already handled centrally in `authFetch`) logs out.
5. **Extra scan fixes (low-risk).**
   - `useUsers` (`src/hooks/useUsers.ts`): refetch group members when the active group changes (currently captures `groupId` at mount → stale after `handleGroupChange`).
   - De-duplicate the user+groups waterfall repeated in `handleGroupCreated` (`Index.tsx`, `Groups.tsx`) — reuse the provider's user + a single groups loader.
6. **Remove React Query.** Delete the `QueryClient`/`QueryClientProvider` from `App.tsx` and drop `@tanstack/react-query` from `package.json` (verify nothing else imports it).

## Acceptance criteria
- Backend: `GET /titles/{id}/episodes` returns episodes (200) / 404 unknown; group-titles list response omits `episodes`, keeps `seasons`. `go build/vet`, `gofmt -l`, unit + integration suites green. Zero `api.Db.` in handlers preserved.
- Frontend: on `/watchlist`, `/groups`, `/account` — Network tab shows **one** `GET /users/me` and **one** movie-list call per load (no duplicates); navigating between pages does not refetch the user; opening a series modal issues one `GET /titles/{id}/episodes`; a simulated user-fetch failure shows an error (not a silent "User") and does not force logout; React Query no longer in the bundle (`grep -r tanstack src` empty; not in `package.json`).
- App builds (`npm run build`) and typechecks.
